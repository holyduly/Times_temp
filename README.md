# 타임스탬프 카메라 (Android)

APK 만드는 법
1. github.com 에서 새 저장소(Repository) 생성
2. 이 폴더의 모든 파일(.github 폴더 포함)을 업로드
3. 저장소의 Actions 탭 → "Build APK" → Run workflow (업로드만 해도 자동 실행)
4. 약 3~6분 후 실행 결과 화면 맨 아래 Artifacts 의 `timestamp-camera-apk` 다운로드
5. 압축을 풀면 app-debug.apk → 휴대폰으로 옮겨 설치 (출처를 알 수 없는 앱 설치 허용 필요)

요구 사항: Android 10 이상
